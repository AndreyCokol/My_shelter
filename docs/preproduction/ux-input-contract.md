# Аудит принятых UX решений (OD-05, OD-09, OD-11, OD-12)
**DRAFT.** A5 — главный интегратор проекта и лично отвечает за весь UI. A0 независимо проверяет A5 и консультирует, A1 — владелец игрового ядра.
**Убежище:** доступно ВСЕГДА, включая до первого зомби, в любой игровой локации и при боевой угрозе. Управление G/кнопка UI. Нет кулдауна, нет награды за побег. Возврат в сохранённую безопасную позицию. Реализация уже в PR #39, не создавать вторую.
**Радиальное меню:** Left Ctrl открывает меню при удержании. Отпускание с выбранным допустимым сектором выполняет одну команду, без выбранного — закрывает без действия; повторное открытие не исполняет прежнюю команду. Перед изменением проверить реальный InputMap в кодовой PR ветке и существующие Issues.
**Графика:** строго top-down 90°. Зомби-мир холодный, серо-зелёный/серо-синий, разруха; убежище тёплое, уютное. Source tiles 128×128: 4 hospital, 4 shelter, 4 grass, 4 asphalt; sprites 64×64 per frame. Logical grid cell — независимая настройка. Nearest filtering.
**UX:** first vertical slice 15–35 min, после Q02 свободная песочница. Проверить вручную native Windows GUI 1280×720 и 1920×1080; GitHub CI/headless не приравнивать к этому тесту.
