# NEW-01/03/04 — UX и арт
Статус DRAFT.
После сюжетного unlock навык входа в убежище доступен во всех обычных управляемых внешних локациях, включая бой, пока владелец не утвердил исключения. При возврате используй сохранённую безопасную точку, не solid tile; при ошибке состояние не меняется. Только ShelterAccessService/SceneRouter изменяет состояние.
Удержание LEFT Ctrl открывает радиальное меню. Отпускание при валидном выборе отправляет ровно одну команду. Отпускание без выбора закрывает меню без команды; повтор не исполняет старый выбор. Right Ctrl не синоним Left Ctrl. UI A5 не изменяет GameState напрямую, A0 проверяет A5.
Камера строго сверху 90°. Зомби-мир холодный, изношенный, мрачный; убежище тёплое и уютное.
Исходные floor tiles 128×128: больница, убежище, трава и асфальт — четыре варианта на категорию; кадр персонажа 64×64, четыре направления, move и attack. Логическая сетка не обязана иметь тот же размер. nearest filtering.
Тесты SHELTER-01, UI-01, ART-01 — PLANNED.
