## Правила оценки

- **DOC-GAP** — подтверждённый пропуск/противоречие в документации.
- **RISK** — возможный программный дефект, который требуется проверить при наличии запускаемой реализации; **не** утверждение о существующем баге.
- **BLOCKER** — отсутствие доказательств, без которых нельзя принять механическую подсистему.
- **PASS** возможен только при ссылке на код, тест, результат прогона и ревизию.
- Статусы `DESIGNED`, `IMPLEMENTED-UNVERIFIED`, `TESTED`, `BLOCKED` не смешивать. Для проверенного `main` P0/P1 — **DESIGNED**, а не `TESTED`.

## 5. Приёмка дополнительных требований владельца

1. **Управление:** InputMap `move_up/down/left/right`=WASD+стрелки; `attack`=ЛКМ; `dodge`=Space; `interact`=E; `radial_menu`=Left Ctrl. Режим `hold` или `toggle` для радиального меню согласовать отдельно; не считать выбранным молча.
2. **HUD/панели:** здоровье, быстрые предметы, навигация, кнопка убежища; панели инвентаря, карты, журнала, фермы, жителей, магазина, сохранения. Каждая панель показывает серверное/локальное состояние только через сервисный API.
3. **Генерация:** для больниц 4 больницы × 4 разных этажа = **16 уникальных планировок**; улицы и жилые дома — отдельные библиотеки сегментов; важны достижимость, корректные входы/выходы, варианты seed и разумный повтор реиспользуемых тайлов.
4. **Масштаб:** улицы увеличены ×12, здания/больницы ×4 относительно **будущего утверждённого baseline**. Не следует выводить итоговый размер пиксельной карты без baseline.
5. **Графика:** холодный тёмный внешний мир зомби против тёплого уютного убежища; игровой top-down **90°**; 128×128 px — требование к ранее запрошенным текстурам пола; 64×64 px — кадры персонажей; UI в чистом pixel art, без непрозрачного фона у отдельных элементов.
6. **Анимации:** 4 направления для персонажей, idle/move/attack по необходимости; выживший не должен иметь необоснованную хромоту. Анимация должна привязываться к velocity и hit windows.

## 6. Обязательная матрица испытаний для готовности

- **Unit**: XP двух прогрессий; инвентарь/стек/монеты; рост/порча; квестовые переходы; resident identity; `GameClock`; migration saves.
- **Property/invariant**: `total_items_before == total_items_after` при переносе, неотрицательный баланс, единственность `action_id`, связность процедурных карт.
- **Integration**: `EventBus` → сервисы → UI; `SceneRouter` → перезапуск → возврат; ферма → погреб → сейв; награда → XP.
- **E2E**: ранее утверждённые E2E-01..05 + E2E-07 радиальное меню и ввод; E2E-08 генерация/достижимость; E2E-09 сейв во время межсценового перехода; E2E-10 повторный запуск после ошибочной записи.
- **Visual/performance**: 1920×1080 и меньшие окна; pixel-perfect и UI с прозрачными элементами; 4 направления анимации; худший процедурный район, 60 FPS как **цель**, не доказанный факт.
- **Evidence record**: `FR/M | owner | commit SHA | test ID | test date | environment | result | screenshots/logs | reviewer`.
