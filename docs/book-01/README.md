# My Shelter — проектные документы песочницы (G0 candidate)

**Концепция владельца (решения 05 и 08.11.2026):** убежище **всегда доступно**, в том числе до первой победы; свободная 2D top-down pixel-art **песочница с сюжетными заданиями по мотивам книги**, реальный бой с атакой/уклонением, естественное время и отдых, **балансный** запас еды, существенная редакторская переработка содержания для широкой аудитории, **весь пространственный осколок отложен**, MVP 15–35 минут и **только личный закрытый прототип**.

**Команда:** A1–A4 пишут свои доменные подсистемы; **A5 — главный агент, самостоятельно пишет весь UI и координирует интеграцию**; **A0 — независимый вертикальный сверщик, reviewer кода A5, его консультант и поддержка**. Назначение в документации само по себе не запускает отдельного процесса.

## Статусы и границы

- **[К]** — сведения из литературного источника; **[П]** — предлагаемая/утверждённая игровая адаптация; **[?]** — не установленное фактическое правило.
- Книга 1 [досье](../../lore/books/01-kartoshka-est.md) — источник стартовых мотивов, не обязательная хронология для игрока; в исследовательском каталоге есть 13 томов, но их механики **не** входят автоматически в игру.
- **G0 ещё не APPROVED:** [Issue #4](https://github.com/AndreyCokol/My_shelter/issues/4). Уже принятые продуктовые решения не равны принятой ревизии API и не являются лицензией начать писать код; для G0 нужны review A1–A5, merge единой документации, owner-approved SHA.
- **Фактическая реализация:** `main` остаётся документационной веткой, однако в цепочке PR #18..52 **уже существует Godot-проект** и пройдены Linux/Windows CI на конкретных SHA; ручная Windows GUI/UX и принятая сборка `main` не подтверждены. Смотреть [сверку P0-01](13-p0-01-live-contract-reconciliation.md).
- Публичное использование литературных имён/узнаваемых защищённых материалов и ассетов требует отдельной проверки прав. **Текущий план распространяется только на закрытый личный прототип.**
