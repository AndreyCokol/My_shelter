**Источники:** предоставленный `604600.fb2.zip` (43 главы) и [досье первого тома](../../lore/books/01-kartoshka-est.md). Полные тексты не копируются в публичный репозиторий.

## Принципы
- **[К] Канон:** подтверждено событиями / интерфейсом первого тома.
- **[П] Проектное решение:** нужная для игры интерпретация, баланс, UX или техническая реализация.
- **[?] Открытый вопрос:** источник не даёт универсального правила; не подменять домыслом.
- Сначала реализовать **пробуждение → Система → убежище → картофель → первый житель**, потом расширять до обороны, осколка и эвакуации.
- Не объявлять готовым проект, которого в GitHub ещё нет. Спецификация — основа для последующей реализации.
- Публикация игры по книге требует выяснить права на адаптацию, даже если тексты книг в репозитории не размещены.

## Зависимости
Сюжет задаёт, **когда** механика открывается; `01-mechanics.md` определяет, **как** она действует; `03-requirements.md` определяет, **как проверить**, что она готова.
