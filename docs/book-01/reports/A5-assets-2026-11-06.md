## Фактическая поставка

- **Kibyra — Free Medieval Fantasy UI Pack:** архив скачан обычным бесплатным flow автора, Readme.txt прочитан; установлены 18 проверенных PNG. Подключены image-backed рамки/Button normal/hover/pressed/focus/disabled, иконки навигации и панелей, значок здоровья HUD, экран авторов. Чёткая фильтрация nearest. Кнопки и заголовки остаются русскими; англоязычные нарисованные menu labels из набора не применяются.
- Installer выбирает только нужные PNG, проверяет SHA архива, ZIP CRC/размер, текст условий и размеры изображений. В public git нет исходных PNG/ZIP; `.gitignore` исключает vendor/. CI устанавливает этот же набор с официальной страницы перед импортом.
- `SHELTER_REQUIRE_ASSETS=1` делает отсутствие изображений ошибкой теста/CI, чтобы placeholders не выдавались за интеграцию. Для чистого source checkout без загруженных артов сохранён тихий fallback; он проверен отдельно.
- **HappyHustle Fantasy Village и Post-Apocalyptic Town:** архивы не получены. Официальные download pages требуют free-claim через itch.io account; доступная browser session не авторизована. Поиск доступных файлов не дал соответствующих ZIP. Ни демо, ни картинки-превью не извлекаются в обход этого доступа. Город/герой/убежище пока сохраняют прежние изображения. Не выдавать этот этап за подключение всех трёх наборов.

[Происхождение, SHA и условия](../asset-licenses.md). Следующий вход: два ZIP HappyHustle, полученные владельцем через itch.io; после этого проверить внутренние LICENSE и реальные animation/pivot metadata, затем подключить игровые текстуры.

## Проверки

Godot 4.7.2.stable.official.ed1daf0bf, Linux.

```sh
python tools/install_ui_assets.py --ui-archive /path/to/Free_Medieval_Fantasy_UI_Pack.zip
python tools/test_asset_installer.py /path/to/Free_Medieval_Fantasy_UI_Pack.zip
SHELTER_REQUIRE_ASSETS=1 GODOT=/path/to/Godot_v4.7.2-stable_linux.x86_64 python tools/run_godot_checks.py
python tools/check_g0_docs.py
git diff --check
```

PASS: все прежние 260 assertions + 39 asset/UI assertions = **299**, 0 failures; import/startup/error+leak scan PASS. Installer: corrupt input не создаёт файлов; точная выборка 18 PNG/атрибуция, повторная установка детерминированна. Source fallback: 2 asset проверки + 34 runtime проверки PASS при временно отсутствующей vendor/директории, затем изображения восстановлены.

Asset suite проверяет реальные Texture2D 32×32 для всех ролей, StyleBoxTexture вместо flat placeholders, hover/pressed/focus состояния, nearest, иконки/границы viewport, title/pause/reopen behavior и credits. Локальный результат не является визуальной оценкой скриншотов.

В CI добавлен software OpenGL renderer под Xvfb и actual viewport captures через run_visual_tests.gd/run_visual_checks.py. Признак PASS требует completion marker без engine/script errors и все 10 PNG сцен/панелей. Windows job тоже устанавливает UI перед suite/export/run. Результаты remote renderer/Windows и новая личная сборка фиксируются после их получения.

Независимое ревью и измерение UX 15–35 минут этим этапом не заменяются. Полный ZIP пакета, browser cookies/download keys и рекламные ссылки не входят в source или сборку.
