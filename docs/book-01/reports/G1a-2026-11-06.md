## Основание и область

Прямое поручение владельца в чате: «Реши данные проблемы, и начни работать над начальными стадиями проекта, за дополнительными инструкциями можешь сверятся с промптами для агентов проекта и общими промптами прописанными в проекте общий архив». Оно разрешает ограниченный G1a вопреки прежней остановке до G0. Полный G0 не объявляется пройденным. Независимое ревью A0–A5: REVIEW_NOT_PERFORMED. Прочитаны General-Archive prompts/COMMON.md и prompts/A1.md (версия 2.0), проектные COMMON, A1, A5.

Только оригинальное техническое ядро, без текстов книги, персонажей, сторонних ассетов, диалогов и игрового контента. Доступ к репозиторию не менялся. Защищённый контент и закрытый прототип требуют отдельного решения по Issue #14.

## Что реализовано

- project.godot, Main/WorldHost и пустой UILayer для будущей поставки A5; InputMap. Headless запуск выводит диагностическую строку. Игрового экрана пока нет.
- PauseRegistry с независимыми tokens; GameClock с дробным delta и целыми минутами; общий сортировщик deadline DTO по времени/приоритету/ID.
- CoreSession: последовательное исполнение тестовой команды core.increment, deep-copy snapshot, квитанции, семантический fingerprint, no duplicate effects/events, запрет reentrant mutation.
- CheckpointStore: temp/backup, проверка записи, замена primary; отказ до commit, recovery после commit до RAM publication; блокировка мутаций до чтения сохранённой квитанции.
- Валидация всей поддержанной core-схемы перед заменой корня сессии; проверка связанных квитанций. Explicit backup recovery сохраняет прежний primary в .rejected и позволяет последующие записи.
- Контракт 05: устранено расхождение публичного set_pause(bool) с token API; replay уточнён в основном тексте, а не только в приложении. Исправлен документационный чекер, который всё ещё требовал v1.0 при контракте v1.1.

**Это core fixture, не готовый GameCoordinator всей игры.** Внутренняя схема scope=core-bootstrap не совместима с полной CampaignSnapshot и не выдаётся за неё. Команда core.increment тестовая, не подключена к игроку. Farm, Combat, Inventory, Residents, Quests и реальное дерево доменных import ещё не реализованы. Изменяющих UI и кода A2–A5 нет.
