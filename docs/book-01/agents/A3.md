## Роль и результат
Ты **A3**. Отвечаешь за первую игровую сцену личного убежища и хозяйственные правила: исходный участок, поле, вода, выращивание картофеля, погреб, простое размещение построек. **Никакого второго инвентаря, GameClock или собственного кошелька.**

**Владение:** `game/scenes/shelter/**`, `game/systems/farming/**`, `game/systems/building/**`, `game/systems/economy/**`, `game/data/crops/**`, `game/data/buildings/**`, `game/tests/shelter/**`. A5 владеет UI/ассетами, A1 — инвентарём/часами/сохранением, A4 — жителями/квестами.

## Канон, который нельзя исказить
- **Г1:** убежище — отдельный участок пространства; исходная площадь — **1 гектар**, граница — туман; наличие укрытия и источника; владелец **не бессмертен**.
- **Г1:** **первый** экземпляр нового вида предмета, принесённого извне, даёт XP убежища; дальнейшие копии — не отдельное начисление. XP пишет A1.
- **Г2:** стартовое поле **40 м²**, картофель при поливе родниковой водой созревает за **72 часа**, через **12 часов** после зрелости без сбора начинает портиться. Эти сроки относятся к стартовому варианту картофеля, не ко всем культурам.
- **Г2:** погреб ёмкостью **10 тонн**, хранимая в нём еда не портится. Не приписывать любому предмету универсальную телепортацию и вечное хранение.

## Модульные контракты
- `FarmService` хранит только `plots/crops` и запрашивает `GameClock.get_hours()`; не использует реальные таймеры интерфейса.
- При сборе ферма выполняет транзакцию `InventoryService.try_add(...)` A1. Лишь **после её успеха** сообщает `crop_harvested`. Подписчик на событие **не добавляет урожай ещё раз**.
- `BuildingService` проверяет занятость территории, ресурсную цену и размещение. `Economy` A3 определяет рецепт/стоимость хозяйственных объектов, A1 проводит списание и выдачу.
- Для `SaveManager` A1 предоставляй `export_state()/import_state(data)` только с сериализуемыми ID, состоянием растений и датами игровых часов.
- A4 владеет потреблением еды жителями; A3 экспортирует запасы/производственные показатели, A4 не пишет состояние грядки.
- A5 получает снапшоты и события, не мутирует урожай напрямую.

## Минимальные проверки
1. Два клика по посадке не создают двойную грядку/семена.
2. Без необходимой воды не происходит штатный цикл.
3. Сохранение на 71-м игровом часу + загрузка + ещё час → зрелость без сброса.
4. Погреб переполнен → транзакция отменена, урожай остаётся у владельца.
5. Сбор дважды → инвентарь пополняется один раз.
6. Через 12 часов после созревания несобранная картошка портится; погреб предотвращает порчу уже убранной еды.
7. E2E-02 и снапшот после перехода сцены.

**Передача A1:** PR с ресурсами `crop/building`, данными состояния и тестами, без правок чужих сцен. Защита от «магической бесконечной картошки» обязательна.
