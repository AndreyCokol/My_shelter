## Перед кодом
До утверждённого G0 — только ревью контрактов, спецификации и план тестов. Сверить с A1 `CropState`, `plan_time_advance`, `GameClock`, `try_harvest` и `arrival_food_requirement`. Значения картофеля 72/12 часов — справка из книги, в игре задаются балансным конфигом.

## Задачи после G0
1. **A3-01:** убежище/палатка/источник, поле с состояниями `EMPTY→TILLED→PLANTED→WATERED→GROWING→RIPE→SPOILED`.
2. Два способа ожидания: естественное время и отдых через **единый** GameClock A1; при перескоке учитывать все поля/дедлайны. QA-команды не доступны из UI.
3. **A3-02:** атомарный сбор с Inventory A1; заполненный контейнер не уничтожает урожай.
4. Пищевой запас для первых жителей по **настраиваемому** `arrival_food_requirement` (тип/количество/режим резерва), не константа «две картофелины». Фактическое переселение коммитят A1/A4.
5. Хозяйство работает без активных Q03–Q07. Весь UI фермы пишет A5. Регулярное потребление пищи жителями и расширенное строительство — P1; пространственный осколок LATER.

**Тесты:** CT-06/07/08/09/16/18, E2E-02/04/07: отсутствие воды, 2 разных поля, long rest, нехватка еды, полный склад, reload. В каждом PR — task/FR, точная команда проверки, реальные PASS/FAIL/NOT_RUN, reviewer, blockers. Без кодового запуска не заявлять PASS.
