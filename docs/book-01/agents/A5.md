## Пока G0 ещё DRAFT
1. Подготовь визуальный гайд: проверить 16×16 и 32×32, **выбор через G0**, единый подход к nearest-neighbor, палитре, масштабированию и русскому тексту.
2. Изучи потенциальные ассеты (больница/Париж, фэнтези-убежище, зомби, UI), документируй лицензию, автора, источник, attribution и статус `APPROVED/PENDING/REJECTED`. «Бесплатно» ≠ разрешено перераспространять.
3. Подготовь UX-макеты: здоровье, два XP, инвентарь, магазин, посылки, **палатка с «Дождаться урожая»**, **резерв 2 картофелин при переселении**, договор, квест. Покажи игроку причину нехватки еды и следующий шаг.
4. Напиши QA-матрицу E2E-01—05 на бумаге, укажи предпосылки и ожидаемые результаты. Без утверждения G0 **не** создавай Godot-сцены/код.

## UI-границы
- Любая кнопка вызывает **команду владельца доменной системы**. Покупка идёт A1; ферма A3; квест A4; бой A2. UI только отображает успех/ошибку и события.
- Двойной клик, повтор отправки после загрузки и отключённая кнопка без видимого статуса не могут выдавать ресурсы дважды: A1 атомарно проверяет, A5 корректно отражает ответ.
- Не копируй PlayerScene или ShelterScene ради спецэффектов: поставляй сцены виджетов, а A1/A2/A3 инстанцируют их.
- Тексты и подписи — локализуемые; UI не должен содержать непроверенного авторского текста книги целиком.
- Визуальные ассеты A5 могут использовать другие агенты через согласованные пути и ID; не перемещай их, ломая ссылки сцены, без миграции.

## Проверки / QA-матрица
| E2E | Точка контроля | Ответственный за фиксацию дефекта |
|---|---|---|
| 01: Больница→Система | Первый kill даёт одну награду; есть экран и вход в убежище | A2, A1, A5 |
| 02: Поле→урожай→погреб | Вода, 72 игровых часа, **ожидание игроком через палатку**, хранение и save/load | A3, A1, A5 |
| 03: Две XP | Второй одинаковый предмет не даёт Shelter XP | A1, A5 |
| 04: Алис/Пирр | Уникальные жители, резерв 2 картофелин, `AWAITING_SUPPLIES`, `job_id`, «Новые лица» | A4, A1, A5 |
| 05: Сохранение | Закрыть/открыть игру и проверить все состояния | A1, A5 |

**UX-01 (G4):** минимум 5 новичков, без внешних подсказок, измерить самостоятельное завершение цикла и осознание пользы еды: **не менее 4/5** для обеих метрик, длительность целевого цикла 15–35 минут [П]. Зафиксировать анонимные ошибки, место затруднения, время, опрос «зачем картофель?». При провале — **UX_FAIL**, правки и повторный плейтест. После G2/G3 провести меньший внутренний UX smoke.

**Для каждого теста:** точные сборка/commit, платформа/версия Godot, шаги, фактический результат, статус PASS/FAIL/SKIP/NOT_RUN и ссылка на доказательства. Если Windows не запускался — `NOT_RUN`; если не проверены лицензии — ассет не входит в итоговую сборку.

## Не делать
Не внедрять скрипты, изменяющие общую валюту, квесты или AI врагов. Не публиковать платные/неразрешённые ресурсы, не «лечить» CI отключением проверок, не объявлять MVP завершённым по скриншоту.
