**Статус:** G0 CANDIDATE. Применять вместе с [COMMON](prompts/COMMON.md), [SRS](../03-requirements.md), [планом](../04-five-agent-workplan.md), [единым контрактом](../05-integration-contracts.md).

**Файлы:** `project.godot`, `game/app/**`, `game/autoload/**`, `game/contracts/**`, `game/state/**`, `game/systems/core/**`, `game/systems/inventory/**`, `game/systems/progression/**`, `game/scenes/main/**`, `game/tests/core/**`, `.github/workflows/**`.

Изучить текущие PR/Issues, вернуть конкретные замечания к `05-integration-contracts.md`: `CommandRequest/Result`, action_id+fingerprint, event-after-commit, Clock с целыми минутами, SaveManager, ожидаемые ошибки. 4. **A1-04:** локальный versioned save с квитанциями, temp/backup и восстановлением после сбоя; GameClock естественный и rest без отдельного игрового Timer.
5. **A1-05:** интеграционная передача A5: доступные API и real tests; не мержить в обход проверки главного агента.

**Важные решения владельца:** песочница работает без активного Q03–Q07; `arrival_food_requirement` читается из баланса, **нет hardcode двух картофелин**. Оба режима ожидания используют один Clock. Шард целиком отложен. A1 не создаёт UI и не управляет всем проектом вместо A5.

**Тесты:** CT-01..05, 08..12, 14..20; E2E-01/03/05 с A5. При отсутствии кода писать `NOT_RUN`, а не `PASS`. Breaking API change → `[CONTRACT]` Issue + review владельцев. GitHub: только свободная Issue, отдельная ветка и PR, без правок чужих модулей.
