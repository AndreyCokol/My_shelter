# A4 — Необязательный сюжет, NPC и добровольные договоры

**G0 CANDIDATE.** Читать [COMMON](prompts/COMMON.md), [02 сюжет](../02-story.md), [03 требования](../03-requirements.md), [04 план](../04-five-agent-workplan.md), [05 API](../05-integration-contracts.md), [09 песочница](../09-sandbox-gameplay-design.md).

**Роль:** сценарные задания, диалоги, контактная зона у Лувра, добровольное заселение, уникальные жители. **Владелец утвердил свободную песочницу по мотивам**, не линейное прохождение первой книги. Взрослые сцены и неравные договоры переработать для широкой аудитории: явное согласие, возможность отказа, без эксплуатационных механик. A5 — главный и единственный разработчик всех UI.

**Владение:** `game/scenes/louvre/**`, `game/systems/residents/**`, `game/systems/quests/**`, `game/systems/dialogue/**`, `game/data/quests/**`, `game/data/dialogue/**`, `game/data/residents/**`, `game/tests/story/**`. UI диалогов и журнала **не** создавать самостоятельно: предоставляет A5.

## До G0
Подготовить схемы Q01–Q07, `QuestState`, `ResidentState`, согласие/отказ NPC и интерфейс событий для A1, не менять игровой код до утверждённого G0.

## После G0
1. **A4-01:** короткие Q01/Q02 разблокируют System/убежище. Q03–Q07 — необязательные сюжетные подсказки: ферма, склад и доступные вылазки работают и без активного задания.
2. **A4-02:** небольшой контакт у Лувра, Алис и Пирр (как временные имена закрытого прототипа), понятные справедливые условия, информированное добровольное согласие и отказ.
3. Состояния `AVAILABLE→CONSENTED→AWAITING_SUPPLIES→RECRUITED`; количество и тип еды задаёт баланс `arrival_food_requirement`, **не две фиксированные картофелины**.
4. Квест «Новые лица» и выдача награды выполняются однократно, без потери согласия при нехватке еды и без дублирования жителей после reload. После выполнения игрок продолжает песочницу.
5. Расширенные задания/массовая эвакуация — будущие **необязательные** ветки по отдельному scope. **ВЕСЬ эпизод пространственного осколка отложен**, не создавать его события, Q12/Q13, карты и обязательные зависимости.

**Интеграция:** A1 проводит атомарный commit еды/жителей/квеста; A3 даёт food rule и хранение; A2 — события мира; A5 делает диалоги/плашки; A0 проверяет вертикальный путь. EventBus уведомляет после commit.

**Тесты:** CT-08/09/17/18/21, E2E-04/07: отказ NPC, нехватка еды, разные правила питания, повторная команда, restart, отсутствие обязательных Q03–Q07. Отчёт — issue/PR/SHA, точно запущенные тесты, PASS/FAIL/NOT_RUN, reviewer.
