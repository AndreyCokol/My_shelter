## Общие правила работы
1. Сначала проверить актуальную ветку, Issues, контракты и чужие открытые PR. Взять **только свободную задачу своего ID**, зарегистрировать владельца в Issue и работать в отдельной ветке `agent/<id>/<task-id>-<slug>`. Если Issues нет — предложить/создать свою задачу до изменения кода (не объявлять её занятой без записи).
2. Не редактировать исходники другого агента. Предлагать изменение контракта через Issue/PR, не внедрять самовольно альтернативный API.
3. Отличать **[К]** (книга 1) от **[П]** (дизайн/баланс), не добавлять события томов 2+. Канонические числа сверять с указанными главами.
4. Для результата нужны тесты, запуск проекта Godot (когда код появится), PR и краткий отчёт: `task | status | commit/PR | tests | blockers | changed contracts`.
5. Новые незафиксированные решения сначала документировать. Никаких прямых изменений `main` при параллельной разработке.

## Миссия
Создать **играбельное исследование разрушенного Парижа и бой**: Сергей выходит из капсулы, находит системное оружие, побеждает зомби и получает доступ к сюжету и дальнейшим вылазкам.

## Исключительные пути
`game/scenes/hospital/**`, `game/scenes/paris/**`, `game/entities/player/**`, `game/entities/enemies/**`, `game/systems/combat/**`, `game/data/enemies/**`, `game/data/loot/**`, `game/tests/combat/**`.

## Наряды
- **A2-01 / P0:** `CharacterBody2D` Сергея, коллизии, анимационные точки подключения к ассетам, ввод/камера, интеракции.
- **A2-02 / P0:** больница, медицинская капсула, переход в руины, стартовый зомби и системное оружие (том 1, гл. 1).
- **A2-03 / P0:** урон и смерть, обычный зомби/быстрый мутант, подбор предметов, лут, базовая улица/маршрут к выжившим; сообщать `enemy_defeated` строго один раз.
- **A2-04 / P1/P2:** расширенные заражённые, защитная волна для убежища (враги и ИИ, сами постройки A3), система редкой награды (таблицы A2, транзакции A1).

## Интеграция
- Не выдавать XP, монеты или книги навыков напрямую: вызвать **публичные** команды A1. Не сохранять копию инвентаря у врага.
- Передавать событие смерти с уникальным `enemy_id` и `action_id`.
- Сцена игрока — переиспользуемая: A1 маршрутизирует между сценами, A3 инстанцирует его в убежище, A4 — в Лувре.
- Не изменять `game/scenes/main/**`, HUD, систему заданий.

## Проверки
1. Пустая больница загружается с плейсхолдерами без внешних ассетов.
2. Игрок упирается в коллизию, а не проходит сквозь стены.
3. Один убитый заражённый → один `enemy_defeated`; повтор сигнала не создаёт дублированную добычу.
4. Внешняя позиция восстанавливается после посещения убежища (через A1).
5. E2E-01 до момента выдачи навыка; тесты AI/боя.
