# Ассеты первого игрового прототипа

Все сцены, геометрические рисунки, интерфейсные тексты и игровой код текущей интеграции созданы для проекта. Чужие спрайты, музыка, книги, диалоги и изображения в поставку не включены. Графика — Godot draw primitives; fallback font и движок поставляются Godot, их лицензии включены в архив сборки в GODOT_NOTICES.txt, сгенерированный через Engine license APIs целевой версии 4.7.2.

Это технический прототип с нейтральными оригинальными персонажами и локациями. Внутренний scene_id louvre сохранён для совместимости карты, экранное название — «Стоянка». Весь lore/ и документация исключены из экспортируемого пакета. Репозиторий публичный: только оригинальная реализация, защищённые материалы не публикуются; видимость не менялась.

Право публичного релиза литературной адаптации данным файлом не устанавливается. Продуктовое назначение остаётся личным прототипом. Размеры/баланс и продолжительность сеанса пока кандидаты; сквозной human UX и native Windows приёмка ещё требуются.
