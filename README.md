# My Shelter

Проект будущей **2D pixel-art игры на Godot** по мотивам серии Дмитрия Дорничева «Моё пространственное убежище».

## Проектирование игры по первой книге

[**Сюжет, механики и требования для Godot**](docs/book-01/README.md) — самостоятельные проектные документы только по первому тому, без событий остальных книг.

## Исследование литературного мира
[**Открыть lore/books/**](lore/books/README.md)

В `lore/books/` находятся:
- сюжетные выжимки всех **13 загруженных томов**;
- каталог из **123 механик** с томами/главами и машинным JSON;
- правила мира, хронология, персонажи и фракции;
- отдельный **дизайн-документ Godot** (предлагаемые, а не канонические правила);
- манифест источников и индекс проверки фактов.

**Статус:** подготовлена текстовая база для разработки; игрового проекта и исполняемой версии пока нет.

**Важно:** материалы являются самостоятельной аналитической выжимкой и не содержат полных текстов книг. Для публичной или коммерческой адаптации необходимо выяснить права на использование произведения.
