# My Shelter — «Моё пространственное убежище»

Проект **локальной 2D pixel-art песочницы с сюжетными заданиями** на Godot 4.x (GDScript) для Windows x64. Свободная игра **по мотивам** литературной серии Дмитрия Дорничева, **не** буквальная экранизация и не жёсткая последовательность глав.

**Решения владельца (2026-11-05):** бой в реальном времени (атака, уклонение, оружие); ферма с естественным ходом времени и безопасным ожиданием; запас еды для жителей настраивается балансом; переработка взрослых тем для широкой аудитории; **весь пространственный осколок отложен**; первый играбельный цикл **15–35 минут**; **только личный закрытый прототип**.

## Подготовка к G0

**[Пакет PRD, механик, песочницы, архитектуры, контрактов, G0, QA и промптов](docs/book-01/README.md)** — единый актуальный набор кандидатов к согласованию.

**Команда:** A1 Core, A2 Combat/Exploration, A3 Shelter/Farm, A4 Narrative/NPC, **A5 — главный агент и единственный разработчик всего UI**, **A0 — независимый вертикальный ревьюер, консультант и поддержка A5**.

**Статус интеграционной ветки:** первый запускаемый прототип: герой/бой/уклонение, четыре оригинальные сцены, убежище/два поля/урожай, часы/отдых, инвентарь/магазин, добровольные жители и русский UI. На Linux Godot 4.7.2 проходят **260 assertions** (core/domain/runtime). Windows export и запуск release .exe headless прошли на native Windows runner; независимое ревью, визуальная приёмка и целевые 15–35 минут не объявлены выполненными. [Ход 17 шагов и ограничения](docs/book-01/reports/17-step-execution-2026-11-06.md).

Запуск исходников: Godot 4.7.2 → `project.godot` → Run. WASD/стрелки — движение, ЛКМ — удар, Space — уклонение, E — взаимодействие, I — инвентарь, Tab — задания, G — убежище после открытия. В окне старта выберите новую игру или продолжение. [Лицензии ассетов](docs/book-01/asset-licenses.md).
