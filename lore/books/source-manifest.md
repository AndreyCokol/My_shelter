## Как определялся порядок
1. Из `<description><title-info><sequence number="…">` извлечён номер книги; разночтения «Мое»/«Моё» и номер «09» нормализованы.
2. Из ZIP использован внутренний FB2-файл; содержимое XML извлечено с учётом возможных ошибок разметки.
3. Повторы исключены по SHA-256 **распакованного FB2**, а не по имени ZIP.
4. Повторные загрузки: `612054.fb2 (1).zip` совпадает с томом 2; `621459.fb2 (1).zip` совпадает с томом 3.
5. Названия файлов и порядковые номера сохранены для проверяемости.

## Как пользоваться источниками
- Ссылка «том N, глава M» относится к последовательности глав соответствующего FB2 (при наличии отдельных послесловий глава проверяется по заголовку).
- Досье передают смысл **парафразом**. Цитаты, полный текст, иллюстрации и вложенные файлы книг **не выкладываются в этот публичный репозиторий**.
- Система, авторский юмор и диалоги персонажей могут противоречить друг другу; «сказал герой» ≠ «универсальное системное правило». Для расчётов и особо важных ограничений сверяйте первоисточник.
- В отдельных книгах присутствуют взрослые темы и жестокое насилие; решения о возрастном рейтинге игры принимаются отдельно.

**Правообладание:** доступ к FB2 для анализа не предоставляет разрешение на коммерческую адаптацию, публикацию первоисточников или заимствование иллюстраций.
