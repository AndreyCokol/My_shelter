# Lore / Books — «Моё пространственное убежище»

> **Спойлеры ко всем 13 томам.** Исследовательская база для разработки 2D pixel-art игры на Godot по мотивам серии Дмитрия Дорничева.

- [Сводка мира](world-bible.md) — устройство вселенной, сущности, ограничения.
- [Каталог механик](mechanics-catalog.md) — **123 описанные механики** с границами применимости и источниками; [машиночитаемая версия](data/mechanics.json).
- [Хронология](timeline.md) — развитие событий и системы от книги к книге.
- [Герои и фракции](characters-factions.md).

- `01-*.md` … `13-*.md` — индивидуальные досье книг.

## Метод и статус
Проанализированы предоставленные 13 уникальных книг в FB2/ZIP (435 XML-секций (включая авторские примечания и послесловия); из файлов исключены повторные копии). В основе заметок — структура глав и текст произведений; формулировки в репозитории являются **самостоятельным пересказом**, а не публикацией текста книг.

Для каждого описания используем три статуса:
- **[КАНОН]** — непосредственно подтверждён событиями / интерфейсными сообщениями в указанном томе (для точных формул см. оригинал).
- **[ВЫВОД]** — обобщение эпизодов, не объявленное системой универсальным правилом.
- **[ДИЗАЙН]** — предлагаемая механика для Godot, отсутствующая в таком виде в тексте.

**Числовые параметры, формулы, способности, названия и ограничения могут изменяться между томами вследствие развития системы.** Нельзя принимать разовые значения из ранней книги за универсальные параметры игры.

## Правила работы над адаптацией
1. Не смешивать художественные факты и игровые предложения.
2. При утверждении механики ссылаться на том и главу; если нет точного подтверждения — помечать [ВЫВОД] или TBD.
3. Сначала прототипировать центральный цикл: вылазка → ресурсы / спасённые → убежище → строительство / хозяйство → улучшение → новая экспедиция.
4. Не размещать в публичном GitHub полные тексты книг, крупные цитаты и иллюстрации без разрешения правообладателя.
5. Проверить права на коммерческую и публичную игровую адаптацию; наличие FB2-файлов не означает наличия лицензии на игру.
6. Для версии с широкой аудиторией отдельно решить судьбу тем жестокости, сексуального контента, рабства и принуждения, присутствующих в сюжете.

Это **рабочая лор-библия**, а не игровая реализация или готовый сценарий.
